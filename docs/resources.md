# Resources

A collection of resources that I have found useful while working on this project.

## Software and Tools

- [Figma](https://www.figma.com/) - Interface design tool.
- [Aseprite](https://www.aseprite.org/) - Pixel art and animation editor.

## Guides, Articles, Tutorials, Videos, and More

- [Trunk Based Development](https://trunkbaseddevelopment.com/) - A source-control branching model, where developers collaborate on code in a single branch called 'trunk', resist any pressure to create other long-lived development branches by employing documented techniques.
- [Google TypeScript Style Guide](https://google.github.io/styleguide/tsguide.html) - The TypeScript style guide used at Google.
- [Google HTML/CSS Style Guide](https://google.github.io/styleguide/htmlcssguide.html) - The HTML/CSS style guide used at Google.
- [How to Make Repeating Border Images](https://css-tricks.com/how-to-make-repeating-border-images/) - A guide on how to make repeating border images in CSS.
